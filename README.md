# Codehaus Plexus site

This repository holds the source for the [Codehaus Plexus organization site](https://codehaus-plexus.github.io/), including the component index and reference pages.

Maintainers publish the site as described in [RELEASING.md](https://github.com/codehaus-plexus/.github/blob/master/RELEASING.md) in the shared `.github` repository.
