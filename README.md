# Codehaus Plexus site

This repository holds the source of the [Codehaus Plexus organization site](https://codehaus-plexus.github.io/):
the list of Plexus libraries, with a link to each project site, and the documentation of the retired
Plexus container. Each library publishes its own site from its own repository.

Run `mvn site` to render the site into `target/site`. Maintainers publish it as described in
[RELEASING.md](https://github.com/codehaus-plexus/.github/blob/master/RELEASING.md) in the shared
`.github` repository. Contributor notes are in [AGENTS.md](AGENTS.md).
